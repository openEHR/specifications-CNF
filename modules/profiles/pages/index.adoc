= {spec_title} [.spec-status.spec-status-development]#{spec_status}#

Definitions of conformance profiles grouping REST API capabilities into coherent subsets. Enables partial conformance claims for implementations supporting specific functionality rather than the full API surface. Profiles are named groupings such as Persistent EHR, Query, or Definitions, allowing vendors to claim conformance at a granularity matching their product scope. A platform may be certified against one or more profiles without having to implement the full openEHR API surface.

== Purpose

This document specifies the openEHR Platform profiles, which may be used to scope conformance testing of openEHR platform products. The audience of this document includes:

* Software development organisations developing healthcare information systems;
* Customer (i.e. procuring) organisations.
